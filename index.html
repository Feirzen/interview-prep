Your marks save on this device right away. Add a GitHub token and they also save to your interview-prep repo, so your phone, laptop, and the widget all stay in sync.

  1. Open GitHub → New fine-grained token.
  2. Name it interview-prep. Set expiration to 90 days.
  3. Under Repository access, pick Only select repositories, then choose interview-prep.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.

The token stays in this browser only. It never goes into the repo.
